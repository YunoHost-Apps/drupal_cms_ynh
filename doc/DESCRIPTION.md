Drupal CMS is a ready-to-use content management platform built on Drupal core, offering smart defaults to get started quickly and enterprise-grade tools for marketers, designers and content creators.

This package installs Drupal CMS by applying the `drupal_cms_starter` site template, which sets up the admin UI, basic content types, SEO tooling, anti-spam and authentication out of the box.

Additional site templates shipped by Drupal CMS (`haven`, `byte`) and the optional recipes (AI, forms, analytics, accessibility tools, SEO tools) are installed on disk and can be applied afterwards with `drush recipe`.
